# Features of the Quiz App:
## User Interface:

* Clean, modern design with a gradient background

* Responsive layout that works on both desktop and mobile devices

* Progress bar to show quiz progression

* Large, easy-to-read text for questions and options

## Quiz Functionality:

* 50 randomly generated questions about squares and cubes

* 3-second time limit per question

* Automatic progression to the next question after selection or time expiration

### Two types of questions:

* "What is the square/cube of X?"

* "Which number's square/cube is Y?"


## Scoring & Review:

* Detailed scorecard showing correct/incorrect answers and percentage

* Time taken to complete the quiz

* Review section showing all questions with your answers and correct answers

* Color-coded responses (green for correct, red for incorrect)

## Additional Features:

* Restart button to take the quiz again

* Instructions page explaining the quiz rules

 * Visual timer countdown for each question
